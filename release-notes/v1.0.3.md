# FEMP-X v1.0.3

This release updates the dataset following additional experiments conducted after ICSME 2026. The counts reported in the ICSME 2026 paper remain those of [version 1.0.1](https://github.com/YoshikiHigo/FEMP-X/releases/tag/v1.0.1).

## Changes since v1.0.2

- Added execution-validated distinguishing tests for **175** pairs previously recorded as `no_witness_found`: **4** from the human-equivalent subset and **171** from the previously uninspected subset.
- The new witnesses comprise **144** `return_value` and **31** `exception` cases. Each candidate was independently reviewed and executed twice per method in fresh JVMs with identical inputs and initial state. Each retained JUnit test passed compilation and targeted Gradle execution, and its corresponding `NoDifferenceTest` was removed.
- Updated the SQLite database's `llm_status`, `difference_type`, and `test_src` fields for the 175 affected pairs. The schema and all table row counts are unchanged. The source and test text for all **13,710** inspected pairs was checked against the repository, with LF line endings for stored test sources.
- Updated the dataset counts, distribution tables, version metadata, and database download link.
- Made the Gradle test environment use LF consistently across operating systems and run all nontermination witnesses in isolated JVMs, including existing tests without a `timeout` tag.
